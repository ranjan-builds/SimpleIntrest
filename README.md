# SimpleIntrest

A simple web app to calculate Simple Interest.

## Features

- **Simple \& Clean UI**: Easily input principal, rate, and time.
- **Automatic Calculation**: Instantly computes the simple interest as you enter values.
- **Front-end Only**: No backend is involved — runs entirely in your browser.


## Getting Started

1. **Clone the repository:**

```bash
git clone https://github.com/ranjan-builds/SimpleIntrest.git
```

2. **Open `index.html` in your browser:**
    - No build steps required.

## Usage

1. Enter the **Principal**, **Rate of Interest**, and **Time** in the provided input fields.
2. The **Simple Interest** will be calculated and displayed automatically.

## File Structure

| File | Description |
| :-- | :-- |
| index.html | Main web page with the user interface. |
| script.js | Logic for calculating simple interest. |
